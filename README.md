# Своя Дача

Сайт загородного дома «Своя Дача» — п. Горный Щит, КП «Улесье», 20 км от
Екатеринбурга. Одностраничный статический сайт, без сборки — открывается
и хостится как есть.

## Структура

Всё содержится в одном файле `index.html`: разметка, стили и фотографии
(встроены как data-URI, отдельных файлов изображений нет — сайт
полностью самодостаточен, ничего не подгружается извне, кроме шрифтов
Google Fonts).

## Что внутри

- Реальный адрес, вместимость (до 6 гостей, 4 взрослых + дети), баня на
  2–3 человека
- Цены и залог, условия размещения
- Правила проживания
- Бронирование и оплата — через объявление на Авито; сайт — витрина,
  ведёт туда и в Instagram

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```

## Публикация на хостинг

Сайт статический — подходит любой хостинг без настройки сборки.

**GitHub Pages** (самый простой вариант, репозиторий уже на GitHub):
1. `Settings → Pages`
2. **Source**: Deploy from a branch
3. **Branch**: `main`, папка `/ (root)` → **Save**
4. Через 1–2 минуты сайт будет доступен на `https://lesinayulia.github.io/svoya-dacha/`

Для своего домена — добавьте файл `CNAME` с адресом домена и настройте
DNS согласно [документации GitHub Pages](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).
